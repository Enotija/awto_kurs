# Awto Szkoła — тренажёр вождения

Браузерный 3D-симулятор для подготовки к польскому экзамену на права категории B.
Вид из-за руля, механическая коробка со сцеплением, три живых зеркала, польские правила.

| Этап | Состояние |
|---|---|
| 1. Машина и кабина | ✅ готово |
| 2. Правила (Польша) | ✅ готово |
| 3. Живой город | в работе |
| 4. Экзамен WORD | в работе |

## Запуск

Нужен **Node.js 20.19+ или 22.12+** ([nodejs.org](https://nodejs.org), на macOS можно `brew install node`).

```bash
npm install     # один раз — скачать зависимости
npm run dev     # запустить; браузер откроется сам на http://localhost:5173
```

Остановить — `Ctrl+C` в терминале.

```bash
npm test        # автотесты логики (механика, дорожная сеть, правила, приоритет)
npm run build   # собрать статическую версию в папку dist/
```

## Как тронуться

1. Выжми сцепление (держи **Shift**) и заведи двигатель — **K**.
2. Не отпуская Shift, включи 1-ю передачу — **E**.
3. Опусти ручник — **Space**. Машина стоит у края дороги: включи левый поворотник (**Z**) и посмотри в левое зеркало (**←**).
4. Держи **W** (обороты ~1500–2000) и отпусти **Shift**. Педаль сцепления поднимается сама примерно за 0,7 с.
   Чтобы тронуться мягче, придерживай её короткими нажатиями Shift в жёлтой зоне шкалы «С» (справа внизу).
5. Переключение: отпусти газ → выжми сцепление → **E** → отпусти сцепление.
6. Перед остановкой выжми сцепление, иначе двигатель заглохнет.

## Управление

| Клавиша | Действие |
|---|---|
| **W / S** | газ / тормоз (нажим нарастает, пока держишь) |
| **A / D** | руль (на ходу возвращается сам, на месте остаётся повёрнутым) |
| **Shift** | сцепление: держишь — выжато, отпустил — поднимается само |
| **E / Q** | передача вверх / вниз (N ↔ 1…5) |
| **R** | задняя (только стоя на месте, со сцеплением) |
| **Space** | ручник вкл / выкл |
| **Z / C** | левый / правый поворотник (ещё раз — выключить; после поворота выключается сам) |
| **H** | аварийка |
| **L** | фары: выкл → ближний → дальний |
| **K** | завести двигатель (при выжатом сцеплении или на нейтрали) |
| **← / →** | взгляд в левое / правое зеркало; держать дольше — через плечо |
| **↑** | взгляд в салонное зеркало |
| **Правая кнопка мыши + мышь** | свободный взгляд |
| **J** | журнал нарушений: последние 5 / все |
| **N** | день / ночь |
| **M** | звук вкл / выкл |
| **Backspace** | вернуть машину на старт |
| **F1 / Esc** | пауза и подсказка |

**Геймпад** (Xbox-раскладка): левый стик — руль, правый курок — газ, левый курок — тормоз,
правый стик вниз — сцепление (плавное), RB / LB — передачи, Y — задняя, X — ручник, B — завести,
крестовина — поворотники (← →), фары (↑), аварийка (↓), правый стик вбок — взгляд, Start — пауза.

## Что готово

### Этап 1 — машина и кабина

- Механика: двигатель с кривой момента, холостым ходом и отсечкой; сцепление с точкой схватывания;
  коробка 5+R (без сцепления — «скрежет», задняя — только на месте).
- Двигатель глохнет, если бросить сцепление без газа, тронуться не с 1-й, остановиться на передаче без сцепления
  или врезаться. На экране — причина.
- Кабина: спидометр, тахометр, передача, лампы; руль, рычаг КПП и ручник двигаются.
- Три зеркала (render-to-texture); взгляд в зеркало или через плечо запоминается.
- Звук синтезируется в браузере, день/ночь, фары.

**Проверить руками:**
1. Shift + K — двигатель заводится, стрелка тахометра ~800. K без сцепления на передаче — подсказка.
2. Тронуться по инструкции выше; отпустить Shift без газа — двигатель глохнет с объяснением.
3. Нажать E без Shift — «скрежет», передача не включается.
4. ← / → / ↑ — в зеркалах видно, что сзади; долгое ← — взгляд через плечо.
5. Z — мигает стрелка на приборах; после поворота налево выключается сама.

### Этап 2 — правила (Польша)

- Город 4×4 перекрёстка: **светофор** с зелёной стрелкой, **rondo**, перекрёсток со **STOP**
  на второстепенной дороге, **равнозначный** перекрёсток (помеха справа), кольцевая улица — главная дорога
  (D-1), выезды на неё — со знаком «уступи дорогу» (A-7), один — со STOP.
- Знаки: B-20 STOP, A-7, D-1, A-5, C-12, B-33 (30 и 40 км/ч), D-6, D-42. Разметка: осевые, стоп-линии,
  «зубы» уступи (P-13), «зебры», пешеходные светофоры.
- Светофор: красный → красный+жёлтый → зелёный → жёлтый; зелёная стрелка — табличка у красного сигнала.
- Журнал нарушений (справа вверху) и счётчик: превышение скорости, красный свет, стрелка без остановки,
  STOP без остановки, манёвр без поворотника, манёвр без взгляда в зеркало, езда по встречной, наезд на бордюр.
  Справа внизу — знак текущего ограничения скорости.
- Логика приоритета (кто кому уступает): помеха справа, главная/второстепенная, налево — уступи встречным,
  rondo, зелёная стрелка. Проверяется на игроке, когда в городе есть машины (этап 3).

**Проверить руками:**
1. Тронуться от края без поворотника — в журнале «Манёвр без поворотника — трогание от края».
2. Доехать до светофора впереди и проехать на красный — «Проезд на красный свет».
3. На красном со стрелкой: полностью остановиться у стоп-линии, включить правый поворотник, посмотреть вправо (→)
   и повернуть направо — нарушений нет. Без остановки — «Зелёная стрелка без полной остановки».
4. Повернуть налево без Z или без взгляда в левое зеркало — соответствующее нарушение.
5. Школьная зона (улица z = 60 между перекрёстками со STOP и равнозначным) — знак 30; проехать 45 км/ч —
   «Сильное превышение». У перекрёстка со STOP не остановиться полностью — «Знак STOP».

## Решения

Где было несколько вариантов, выбрал так:

- **Сцепление с клавиатуры.** Педаль отпускается сама за ~0,7 с (иначе нельзя «бросить» сцепление);
  плавно — короткими нажатиями Shift. На геймпаде — аналоговая педаль.
- **«Фокус взгляда».** При взгляде в зеркало клавишей вид приближается к нему — иначе правое зеркало
  на мониторе крошечное.
- **Зелёная стрелка** — это табличка на светофоре (в Польше это не отдельный сигнал). Действует при красном:
  поворот направо только после полной остановки.
- **Жёлтый не наказывается** (правила разрешают проехать, если нельзя безопасно остановиться);
  красный+жёлтый считается красным.
- **Полная остановка** — скорость ниже 0,6 км/ч в зоне 12 м перед стоп-линией.
- **Ограничение B-33 действует до ближайшего перекрёстка** — как в польских правилах.
- **Допуск спидометра +3 км/ч.** Превышение больше чем на 10 км/ч — отдельное, «критическое» нарушение.
- **Поворотник** должен гореть в момент пересечения стоп-линии. На rondo на въезде поворотник не нужен,
  перед съездом — правый (польская практика).
- **Зеркало перед манёвром:** взгляд засчитывается за 10 с до въезда на перекрёсток (или в первые 1,5 с поворота).
  Направо — правое зеркало или через правое плечо, налево — левое. Салонное зеркало боковое не заменяет.
  Взгляд засчитывается, если задержаться на зеркале хотя бы 0,12 с.
- **Трогание от края** — нужен левый поворотник и взгляд в левое зеркало.
- На столбе у rondo **A-7 висит над C-12**.

## Известные проблемы

- Бордюр — твёрдая стена: на тротуар заехать нельзя (на экзамене наезд на бордюр — ошибка, так что это не мешает).
- Звук и геймпад проверены только в коде (в автоматических проверках нет динамиков и контроллера).

## Структура кода

```
src/
  main.js               запуск, игровой цикл, свет, сообщения
  car/
    physics/            физика без графики (её гоняют тесты)
    playerCar.js        сборка машины: физика + графика + фары + столкновения
    cockpit.js cluster.js mirrors.js driverView.js carBody.js signals.js layers.js
  world/
    roadNetwork.js      дорожная сеть: перекрёстки, полосы, траектории, переходы, знаки (без графики)
    geometry.js         геометрия на плоскости (без графики)
    city.js             отрисовка города по сети
    signs.js            польские знаки (canvas)
    trafficLightsView.js светофоры
  rules/
    lights.js           цикл светофора (без графики)
    rules.js            движок правил: нарушения игрока (без графики)
    priority.js         кто кому уступает (без графики)
    violations.js       каталог нарушений
  input/ ui/ audio/     ввод, интерфейс, звук
  debug/autopilot.js    автопилот для автоматических проверок в браузере
tests/                  автотесты (npm test)
```

Для отладки в консоли браузера доступен объект `sim`
(например, `sim.car.physics.rpm`, `sim.rules.log` или `sim.advance(1)` — прогнать игру на 1 секунду).
