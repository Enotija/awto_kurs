# Awto Szkoła — тренажёр вождения

Браузерный 3D-симулятор для подготовки к польскому экзамену на права категории B.
Вид из-за руля, механическая коробка со сцеплением, три живых зеркала.

**Готово:** этап 1 — машина и кабина.
Дальше по плану: правила дорожного движения (этап 2), живой город (этап 3), режим экзамена WORD (этап 4).

## Запуск

Нужен **Node.js 20.19+ или 22.12+** ([nodejs.org](https://nodejs.org), на macOS можно `brew install node`).

```bash
npm install     # один раз — скачать зависимости
npm run dev     # запустить; браузер откроется сам на http://localhost:5173
```

Остановить — `Ctrl+C` в терминале.

Другие команды:

```bash
npm test        # автотесты механики (двигатель, сцепление, коробка, поворотники)
npm run build   # собрать статическую версию в папку dist/
```

## Как тронуться

1. Выжми сцепление (держи **Shift**) и заведи двигатель — **K**.
2. Не отпуская Shift, включи 1-ю передачу — **E**.
3. Опусти ручник — **Space**.
4. Держи **W** (обороты ~1500–2000) и отпусти **Shift**. Педаль сцепления поднимается сама примерно за 0,7 с.
   Чтобы тронуться мягче, придерживай её короткими нажатиями Shift в жёлтой зоне шкалы «С» (справа внизу).
5. Переключение: отпусти газ → выжми сцепление → **E** → отпусти сцепление.
6. Перед остановкой выжми сцепление, иначе двигатель заглохнет.

## Управление

| Клавиша | Действие |
|---|---|
| **W / S** | газ / тормоз (нажим нарастает, пока держишь) |
| **A / D** | руль (на ходу возвращается сам, на месте остаётся повёрнутым) |
| **Shift** | сцепление: держишь — выжато, отпустил — поднимается само |
| **E / Q** | передача вверх / вниз (N ↔ 1…5) |
| **R** | задняя (только стоя на месте, со сцеплением) |
| **Space** | ручник вкл / выкл |
| **Z / C** | левый / правый поворотник (ещё раз — выключить; после поворота выключается сам) |
| **H** | аварийка |
| **L** | фары: выкл → ближний → дальний |
| **K** | завести двигатель (при выжатом сцеплении или на нейтрали) |
| **← / →** | взгляд в левое / правое зеркало; держать дольше — через плечо |
| **↑** | взгляд в салонное зеркало |
| **Правая кнопка мыши + мышь** | свободный взгляд |
| **N** | день / ночь |
| **M** | звук вкл / выкл |
| **Backspace** | вернуть машину на старт |
| **F1 / Esc** | пауза и подсказка |

**Геймпад** (Xbox-раскладка): левый стик — руль, правый курок — газ, левый курок — тормоз,
правый стик вниз — сцепление (плавное), RB / LB — передачи, Y — задняя, X — ручник, B — завести,
крестовина — поворотники (← →), фары (↑), аварийка (↓), правый стик вбок — взгляд, Start — пауза.

## Что реализовано в этапе 1

- **Механика как в жизни.** Двигатель с кривой момента, холостым ходом и отсечкой. Сцепление с точкой схватывания.
  Коробка 5+R: передача не включается без выжатого сцепления («скрежет»), задняя — только на месте.
- **Двигатель глохнет,** если бросить сцепление без газа, тронуться не с 1-й передачи, затормозить до остановки
  на передаче без сцепления или врезаться. На экране — причина.
- **Кабина:** спидометр, тахометр, индикатор передачи, лампы (поворотники, ближний/дальний, ручник, аккумулятор, масло).
  Руль, рычаг КПП и ручник двигаются.
- **Три зеркала** — отдельные камеры рисуют вид назад в текстуру (render-to-texture).
  Каждый взгляд в зеркало или через плечо запоминается — пригодится для правил на этапе 2.
- **Квартал:** две улицы крест-накрест с перекрёстком и «зебрами», кольцевая улица по периметру, дома, деревья, фонари.
  Бордюры твёрдые.
- **Звук** синтезируется в браузере, файлов нет.

## Структура кода

```
src/
  main.js               запуск, игровой цикл, свет, сообщения
  car/
    physics/            физика без графики (её гоняют тесты)
      params.js         параметры машины и двигателя
      engine.js         двигатель: момент, холостой ход, стартер, заглохание
      gearbox.js        коробка передач
      carPhysics.js     сцепление, тормоза, движение и поворот
    playerCar.js        сборка машины: физика + графика + фары + столкновения
    cockpit.js          салон, руль, рычаги
    cluster.js          приборная панель (рисуется на canvas)
    mirrors.js          три зеркала
    driverView.js       камера водителя, взгляд в зеркала и через плечо
    carBody.js          кузов снаружи (виден в боковых зеркалах)
    signals.js          поворотники, аварийка, фары
    layers.js           какие камеры что видят
  world/                город: улицы, разметка, дома, деревья
  input/                клавиатура и геймпад
  ui/                   экранный интерфейс
  audio/                звук
  rules/ traffic/ exam/ — для этапов 2–4
tests/                  автотесты (npm test)
```

Для отладки в консоли браузера доступен объект `sim`
(например, `sim.car.physics.rpm` или `sim.advance(1)` — прогнать игру на 1 секунду).
