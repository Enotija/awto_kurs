# Awto Szkoła — тренажёр вождения

Браузерный 3D-симулятор для подготовки к польскому экзамену на права категории B.
Вид из-за руля, механическая коробка со сцеплением, три живых зеркала, польские правила.

| Этап | Состояние |
|---|---|
| 1. Машина и кабина | ✅ готово |
| 2. Правила (Польша) | ✅ готово |
| 3. Живой город | ✅ готово |
| 4. Экзамен WORD | ✅ готово |

## Запуск

Нужен **Node.js 20.19+ или 22.12+** ([nodejs.org](https://nodejs.org), на macOS можно `brew install node`).

```bash
npm install     # один раз — скачать зависимости
npm run dev     # запустить; браузер откроется сам на http://localhost:5173
```

Остановить — `Ctrl+C` в терминале.

```bash
npm test        # 77 автотестов логики: механика, сеть, правила, приоритет, ИИ, экзамен
npm run build   # собрать статическую версию в папку dist/
```

## Режимы (главное меню)

- **Свободная езда** — город с правилами, журналом нарушений и живым движением.
- **Экзамен WORD** — площадка (łuk, горка, одна из трёх парковок) и маршрут по городу с экзаменатором.
  Итог — **ZDAŁ / NIE ZDAŁ** с причинами.
- **Площадка — тренировка** — все задания площадки подряд: łuk, горка, три парковки.

**Esc / F1** — пауза и меню (продолжить или выйти в главное меню).

## Как тронуться

1. Выжми сцепление (держи **Shift**) и заведи двигатель — **K**.
2. Не отпуская Shift, включи 1-ю передачу — **E**.
3. Опусти ручник — **Space**. Машина стоит у края дороги: включи левый поворотник (**Z**) и посмотри в левое зеркало (**←**).
4. Держи **W** (обороты ~1500–2000) и отпусти **Shift**. Педаль сцепления поднимается сама примерно за 0,7 с.
   Чтобы тронуться мягче, придерживай её короткими нажатиями Shift в жёлтой зоне шкалы «С» (справа внизу).
5. Переключение: отпусти газ → выжми сцепление → **E** → отпусти сцепление.
6. Перед остановкой выжми сцепление, иначе двигатель заглохнет.

## Управление

| Клавиша | Действие |
|---|---|
| **W / S** | газ / тормоз (нажим нарастает, пока держишь) |
| **A / D** | руль (на ходу возвращается сам, на месте остаётся повёрнутым) |
| **Shift** | сцепление: держишь — выжато, отпустил — поднимается само |
| **E / Q** | передача вверх / вниз (N ↔ 1…5) |
| **R** | задняя (только стоя на месте, со сцеплением) |
| **Space** | ручник вкл / выкл |
| **Z / C** | левый / правый поворотник (ещё раз — выключить; после поворота выключается сам) |
| **H** | аварийка |
| **L** | фары: выкл → ближний → дальний |
| **K** | завести двигатель (при выжатом сцеплении или на нейтрали) |
| **← / →** | взгляд в левое / правое зеркало; держать дольше — через плечо |
| **↑** | взгляд в салонное зеркало |
| **Правая кнопка мыши + мышь** | свободный взгляд |
| **J** | журнал нарушений: последние 5 / все |
| **N** | день / ночь |
| **M** | звук вкл / выкл |
| **V** | голос экзаменатора вкл / выкл (польский, если есть в системе) |
| **Backspace** | на старт (в тренировке площадки — начать задание заново; на экзамене нельзя) |
| **F1 / Esc** | пауза и меню |

**Геймпад** (Xbox-раскладка): левый стик — руль, правый курок — газ, левый курок — тормоз,
правый стик вниз — сцепление (плавное), RB / LB — передачи, Y — задняя, X — ручник, B — завести,
крестовина — поворотники (← →), фары (↑), аварийка (↓), правый стик вбок — взгляд, Start — пауза.

## Что готово

### Этап 1 — машина и кабина

- Механика: двигатель с кривой момента, холостым ходом и отсечкой; сцепление с точкой схватывания;
  коробка 5+R (без сцепления — «скрежет», задняя — только на месте).
- Двигатель глохнет, если бросить сцепление без газа, тронуться не с 1-й, остановиться на передаче без сцепления
  или врезаться. На экране — причина.
- Кабина: спидометр, тахометр, передача, лампы; руль, рычаг КПП и ручник двигаются.
- Три зеркала (render-to-texture); взгляд в зеркало или через плечо запоминается.
- Звук синтезируется в браузере, день/ночь, фары.

**Проверить руками:**
1. Shift + K — двигатель заводится, стрелка тахометра ~800. K без сцепления на передаче — подсказка.
2. Тронуться по инструкции выше; отпустить Shift без газа — двигатель глохнет с объяснением.
3. Нажать E без Shift — «скрежет», передача не включается.
4. ← / → / ↑ — в зеркалах видно, что сзади; долгое ← — взгляд через плечо.
5. Z — мигает стрелка на приборах; после поворота налево выключается сама.

### Этап 2 — правила (Польша)

- Город 4×4 перекрёстка: **светофор** с зелёной стрелкой, **rondo**, перекрёсток со **STOP**
  на второстепенной дороге, **равнозначный** перекрёсток (помеха справа), кольцевая улица — главная дорога
  (D-1), выезды на неё — со знаком «уступи дорогу» (A-7), один — со STOP.
- Знаки: B-20 STOP, A-7, D-1, A-5, C-12, B-33 (30 и 40 км/ч), D-6, D-42. Разметка: осевые, стоп-линии,
  «зубы» уступи (P-13), «зебры», пешеходные светофоры.
- Светофор: красный → красный+жёлтый → зелёный → жёлтый; зелёная стрелка — табличка у красного сигнала.
- Журнал нарушений (справа вверху) и счётчик: превышение скорости, красный свет, стрелка без остановки,
  STOP без остановки, манёвр без поворотника, манёвр без взгляда в зеркало, езда по встречной, наезд на бордюр.
  Справа внизу — знак текущего ограничения скорости.
- Логика приоритета (кто кому уступает): помеха справа, главная/второстепенная, налево — уступи встречным,
  rondo, зелёная стрелка. Проверяется на игроке, когда в городе есть машины (этап 3).

**Проверить руками:**
1. Тронуться от края без поворотника — в журнале «Манёвр без поворотника — трогание от края».
2. Доехать до светофора впереди и проехать на красный — «Проезд на красный свет».
3. На красном со стрелкой: полностью остановиться у стоп-линии, включить правый поворотник, посмотреть вправо (→)
   и повернуть направо — нарушений нет. Без остановки — «Зелёная стрелка без полной остановки».
4. Повернуть налево без Z или без взгляда в левое зеркало — соответствующее нарушение.
5. Школьная зона (улица z = 60 между перекрёстками со STOP и равнозначным) — знак 30; проехать 45 км/ч —
   «Сильное превышение». У перекрёстка со STOP не остановиться полностью — «Знак STOP».

### Этап 3 — живой город

- **ИИ-машины** (24) ездят по всему городу со случайными маршрутами и соблюдают те же правила:
  светофоры, зелёную стрелку (сначала полная остановка), STOP, «уступи», помеху справа, rondo,
  налево — уступают встречным. Держат дистанцию (модель IDM), включают поворотники и стоп-сигналы,
  не заезжают на перекрёсток, если съезд занят. Всё, что оказалось у них на пути, включая твою машину, —
  тормозят. Если ты стоишь у края дольше ~4 с, объезжают по встречке, когда она свободна.
- **Велосипедисты** (6) едут у правого края дороги; ИИ обгоняет их с интервалом не меньше 1,2 м.
  Ещё трое катаются по красной велодорожке вокруг квартала у старта (знаки C-13).
- **Пешеходы** (24) ходят туда-обратно через все переходы: на регулируемых — по своему зелёному,
  на остальных — когда подъезжающая машина дальше ~4 с.
- **Новые нарушения игрока:** не уступил дорогу (помеха справа, главная дорога, налево против встречных, rondo),
  не пропустил пешехода, обгон велосипедиста ближе 1 м, столкновение с машиной или человеком.

**Проверить руками:**
1. Постоять у светофора — ИИ-машины останавливаются на красный, поворачивающие направо у стрелки сначала
   полностью встают; пешеходы переходят на свой зелёный.
2. Встать посреди полосы и подождать — машины сзади тормозят, через несколько секунд объезжают.
3. На равнозначном перекрёстке (x = 60, z = 60) въехать, когда справа подъезжает машина, —
   «Не уступил дорогу — помеха справа».
4. Проехать «зебру», когда по ней идёт пешеход, — «Не пропустил пешехода».
5. Обогнать велосипедиста впритирку — «Опасный обгон велосипедиста (ближе 1 м)».

### Этап 4 — экзамен WORD

- **Площадка (plac manewrowy)** к востоку от города:
  - **łuk** — вперёд по полосе до жёлтой зоны у конечной линии, затем задом по дуге обратно в стартовую зону;
  - **трогание в горку** (подъём 12 %) — остановиться передним бампером между жёлтыми линиями
    на подъёме и тронуться, не откатившись назад больше чем на 20 см и не заглохнув;
  - **парковка** — перпендикулярная, параллельная (задом, к бордюру) и под углом 60° между стоящими машинами:
    все четыре колеса внутри линий, затем ручник.

  Колесо на линии, задетый пачоук (конус), стоящая машина или бордюр — ошибка. На каждое задание 2 попытки.
- **Город с экзаменатором:** маршрут из 8 манёвров строится случайно, но обязательно через светофор, rondo,
  STOP и равнозначный перекрёсток. Команды экзаменатора — на польском с переводом
  («Na najbliższym skrzyżowaniu proszę skręcić w prawo», «Na rondzie proszę zjechać drugim zjazdem»),
  голосом — по клавише V. Свернул не туда — это не ошибка, экзаменатор перестраивает маршрут.
  В конце — остановиться у правого края и затянуть ручник.
- **Оценка как на экзамене:** критическое нарушение (красный, STOP, пешеход, помеха, сильное превышение,
  встречная, столкновение, опасный обгон велосипедиста) — экзамен сразу прерывается; одна и та же
  некритическая ошибка второй раз — «не сдал»; два провала одного задания на площадке — «не сдал».
- Экран итога: ZDAŁ / NIE ZDAŁ, причина, результаты заданий площадки и все ошибки (по-русски и по-польски).

**Проверить руками:**
1. Меню → «Экзамен WORD»: машина на старте łuk, слева вверху панель экзаменатора с командой.
   Заведи машину, проедь вперёд и остановись передним бампером в жёлтой зоне — команда сменится на «задом».
2. Задень линию łuk колесом — «Колесо наехало на линию», вторая попытка; второй раз — NIE ZDAŁ.
3. Меню → «Площадка — тренировка»: на горке остановись в жёлтой зоне и опусти ручник на нейтрали — машина
   покатится назад, ошибка «откат больше 20 см». С ручником и плавным сцеплением — зачёт.
4. На парковке встань всеми колёсами в место с жёлтой линией и затяни ручник — «Задание выполнено».
5. В городской части проедь на красный — сразу NIE ZDAŁ «Przerwanie egzaminu». Проедь маршрут без
   критических ошибок и остановись у края с ручником — ZDAŁ.

## Решения

Где было несколько вариантов, выбрал так:

- **Сцепление с клавиатуры.** Педаль отпускается сама за ~0,7 с (иначе нельзя «бросить» сцепление);
  плавно — короткими нажатиями Shift. На геймпаде — аналоговая педаль.
- **«Фокус взгляда».** При взгляде в зеркало клавишей вид приближается к нему — иначе правое зеркало
  на мониторе крошечное.
- **Зелёная стрелка** — это табличка на светофоре (в Польше это не отдельный сигнал). Действует при красном:
  поворот направо только после полной остановки.
- **Жёлтый не наказывается** (правила разрешают проехать, если нельзя безопасно остановиться);
  красный+жёлтый считается красным.
- **Полная остановка** — скорость ниже 0,6 км/ч в зоне 12 м перед стоп-линией.
- **Ограничение B-33 действует до ближайшего перекрёстка** — как в польских правилах.
- **Допуск спидометра +3 км/ч.** Превышение больше чем на 10 км/ч — отдельное, «критическое» нарушение.
- **Поворотник** должен гореть в момент пересечения стоп-линии. На rondo на въезде поворотник не нужен,
  перед съездом — правый (польская практика).
- **Зеркало перед манёвром:** взгляд засчитывается за 10 с до въезда на перекрёсток (или в первые 1,5 с поворота).
  Направо — правое зеркало или через правое плечо, налево — левое. Салонное зеркало боковое не заменяет.
  Взгляд засчитывается, если задержаться на зеркале хотя бы 0,12 с.
- **Трогание от края** — нужен левый поворотник и взгляд в левое зеркало.
- На столбе у rondo **A-7 висит над C-12**.
- **ИИ угадывает твой манёвр по поворотнику**: без поворотника считает, что ты едешь прямо.
  Если поворотник не тот — ИИ может ошибиться в приоритете, но в тебя всё равно не въедет:
  он тормозит перед любым препятствием на своём пути.
- **«Не уступил дорогу»** — если в момент твоего въезда на перекрёсток машина с приоритетом доехала бы до него
  быстрее чем за 2,8 с (или уже ехала через него по пересекающейся траектории).
- **Пешеход на переходе** считается помехой, если он уже на проезжей части и идёт в пределах 4,5 м от твоей
  траектории или в её сторону. Пешеход, ждущий на тротуаре, — не нарушение.
- **Интервал до велосипедиста** меряется от борта машины до велосипедиста, пока вы рядом и ты быстрее.
- **Велосипедисты на велодорожке** — «фон»: с машинами не пересекаются.
- ИИ-машина, застрявшая больше 45 с вдали от тебя (дальше 80 м), переставляется в другое место города.
- **Парковки — на площадке**, как было в задании (на настоящем экзамене их делают в городском движении).
  На экзамене экзаменатор выбирает одну из трёх случайно, в тренировке — все три.
- **Ширина полосы łuk — 3,0 м** (на настоящем экзамене около 2,5 м): с клавиатурой точнее не проехать.
  Поменять можно в `LUK.width` в `src/exam/yardLayout.js`.
- **«Касание линии»** — колесо (с учётом ширины шины) заходит на линию; кузов может нависать.
  Парковка засчитывается, когда все четыре колеса внутри места и затянут ручник.
- **Горка:** остановка засчитывается, если передний бампер между жёлтыми линиями; откат больше 20 см или
  заглохший при трогании двигатель — ошибка попытки.
- **Ближний свет в городе обязателен** (в Польше — и днём). Движение без него — некритическая ошибка.
- **Площадка не связана дорогой с городом:** после площадки машина переносится на старт в городе.
- **Голос экзаменатора выключен по умолчанию** (V): зависит от голосов в системе, польского может не быть.

## Известные проблемы

- Бордюр — твёрдая стена: на тротуар заехать нельзя (на экзамене наезд на бордюр — ошибка, так что это не мешает).
- ИИ не обгоняет медленные машины — только велосипедистов и стоящую машину игрока.
- ИИ-машины движутся точно по траекториям полос (без физики заносов); при ударе просто останавливаются.
- Польский голос экзаменатора есть не во всех системах (на Linux часто нет) — тогда читается голосом по умолчанию,
  текст команды всегда на экране.
- На площадке машины ИИ нет: там только твоя машина и стоящие на парковке.
- Отладочный автопилот (`sim.autopilot`) — инструмент проверки, правил он не соблюдает.
- Звук и геймпад проверены только в коде (в автоматических проверках нет динамиков и контроллера).
